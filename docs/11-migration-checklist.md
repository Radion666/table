## Откат

Если что-то пошло не так:
1. `docker compose down` (остановить FastAPI)
2. Восстановить `docker-compose.yml` на NestJS
3. `docker compose up -d --build` (старый бэкенд)
4. Данные в БД не затронуты — откат бесшовный
